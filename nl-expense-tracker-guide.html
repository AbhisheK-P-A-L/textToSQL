Implementation Guide

Natural Language Expense Tracker
with AI Insights

Build a Spring Boot backend that accepts natural language expense input (e.g. "I spent 300 bucks on Amazon today"), parses it using an LLM, and generates AI-powered spending insights.

Expense Entity

model/Expense.java

This JPA entity stores both the parsed structured data and the original raw input from the user. Keeping rawInput allows you to re-parse later if your prompt improves.

Expense.java
@Entity
@Data
@Table(name = "expenses")
public class Expense {

    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private String id;

    private String userId;            // scoped per authenticated user

    private BigDecimal amount;
    private String currency;          // "INR", "USD", etc.

    @Enumerated(EnumType.STRING)
    private Category category;        // FOOD, SHOPPING, TRAVEL, HEALTH,
                                      // ENTERTAINMENT, UTILITIES, OTHER

    private String vendor;            // "Amazon", "Zomato" — nullable
    private String description;       // cleaned short description
    private LocalDate expenseDate;    // parsed or today if absent
    private String rawInput;          // original natural language text

    @CreationTimestamp
    private LocalDateTime createdAt;
}

// Category enum (in same package)
public enum Category {
    FOOD, SHOPPING, TRAVEL, HEALTH, ENTERTAINMENT, UTILITIES, OTHER
}

NLP Parsing Service

service/NLPParsingService.java — the core magic

This service sends the raw user text to GPT with a tightly constrained system prompt. The model returns only a JSON object — no preamble. Temperature is set to 0.0 to get deterministic, consistent parsing every time.

✓

Always inject today's date into the prompt so the model can resolve relative expressions like "today", "yesterday", or "last Friday" correctly.

NLPParsingService.java
@Service
@RequiredArgsConstructor
public class NLPParsingService {

    private final OpenAiService openAiService;
    private final ObjectMapper objectMapper;

    private static final String SYSTEM_PROMPT = """
        You are an expense parser. Given a natural language expense description,
        extract structured data and return ONLY valid JSON — no explanation,
        no markdown, no extra text. The JSON must follow this exact shape:

        {
          "amount": <number>,
          "currency": "<3-letter ISO code, default INR>",
          "category": "<one of: FOOD, SHOPPING, TRAVEL, HEALTH, ENTERTAINMENT, UTILITIES, OTHER>",
          "vendor": "<merchant or platform name, or null if unknown>",
          "description": "<short cleaned description, max 10 words>",
          "expenseDate": "<YYYY-MM-DD — use today's date if not mentioned>"
        }

        Examples:
        Input:  "i spent 300 bucks on amazon today"
        Output: {"amount":300,"currency":"INR","category":"SHOPPING",
                  "vendor":"Amazon","description":"Purchase on Amazon",
                  "expenseDate":"2025-05-21"}

        Input:  "grabbed lunch at zomato for 150"
        Output: {"amount":150,"currency":"INR","category":"FOOD",
                  "vendor":"Zomato","description":"Lunch via Zomato",
                  "expenseDate":"2025-05-21"}

        Input:  "paid 2000 for doctor visit last monday"
        Output: {"amount":2000,"currency":"INR","category":"HEALTH",
                  "vendor":null,"description":"Doctor visit",
                  "expenseDate":"2025-05-19"}
        """;

    public ParsedExpense parse(String naturalLanguageInput) {
        String today = LocalDate.now().toString();

        List<ChatMessage> messages = List.of(
            new ChatMessage("system", SYSTEM_PROMPT),
            new ChatMessage("user",
                "Today is " + today + ". Parse this: " + naturalLanguageInput)
        );

        ChatCompletionRequest request = ChatCompletionRequest.builder()
            .model("gpt-4o")
            .messages(messages)
            .temperature(0.0)    // deterministic output
            .maxTokens(300)
            .build();

        String jsonResponse = openAiService
            .createChatCompletion(request)
            .getChoices().get(0)
            .getMessage()
            .getContent()
            .trim();

        try {
            return objectMapper.readValue(jsonResponse, ParsedExpense.class);
        } catch (JsonProcessingException e) {
            throw new RuntimeException("Failed to parse LLM response: " + jsonResponse, e);
        }
    }
}

Expense Service

service/ExpenseService.java
ExpenseService.java
@Service
@RequiredArgsConstructor
public class ExpenseService {

    private final ExpenseRepository expenseRepository;
    private final NLPParsingService nlpParsingService;

    public Expense saveFromNaturalLanguage(String rawText, String userId) {
        ParsedExpense parsed = nlpParsingService.parse(rawText);

        Expense expense = new Expense();
        expense.setUserId(userId);
        expense.setAmount(parsed.getAmount());
        expense.setCurrency(parsed.getCurrency());
        expense.setCategory(parsed.getCategory());
        expense.setVendor(parsed.getVendor());
        expense.setDescription(parsed.getDescription());
        expense.setExpenseDate(parsed.getExpenseDate());
        expense.setRawInput(rawText);              // preserve original input

        return expenseRepository.save(expense);
    }

    public List<Expense> getAllByUser(String userId) {
        return expenseRepository.findByUserId(userId);
    }

    public List<Expense> getByUserSince(String userId, LocalDate since) {
        return expenseRepository.findByUserIdAndExpenseDateAfter(userId, since);
    }

    public void delete(String expenseId, String userId) {
        Expense expense = expenseRepository.findById(expenseId)
            .orElseThrow(() -> new RuntimeException("Expense not found"));
        if (!expense.getUserId().equals(userId)) {
            throw new SecurityException("Access denied");
        }
        expenseRepository.delete(expense);
    }
}

Insights Service

service/InsightsService.java

This service aggregates the user's expense data, builds a readable summary, and sends it to GPT with a finance-advisor prompt. Results are cached in Redis to avoid repeated expensive API calls.

✓

Use temperature 0.7 here (unlike the parser) — a slightly creative tone produces more natural, readable financial advice.

InsightsService.java
@Service
@RequiredArgsConstructor
public class InsightsService {

    private final OpenAiService openAiService;
    private final ExpenseService expenseService;
    private final StringRedisTemplate redisTemplate;

    @Value("${app.insights.cache-ttl-hours}")
    private int cacheTtlHours;

    public String generateInsights(String userId, int days) {
        String cacheKey = "insights:" + userId + ":" + days;

        // Return cached result if available
        String cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) return cached;

        // Fetch and summarize spending data
        LocalDate since = LocalDate.now().minusDays(days);
        List<Expense> expenses = expenseService.getByUserSince(userId, since);

        if (expenses.isEmpty()) {
            return "No expenses found in the last " + days + " days.";
        }

        String summary = buildSummary(expenses);

        String prompt = """
            You are a personal finance advisor reviewing a user's spending.
            Provide a concise analysis covering:
            1. Top spending categories and whether any seem excessive
            2. Any unusual one-off expenses worth flagging
            3. One actionable money-saving tip based on the actual data
            4. Overall spending health score out of 10 with a brief reason

            User's spending data (last %d days):
            %s
            """.formatted(days, summary);

        ChatCompletionRequest request = ChatCompletionRequest.builder()
            .model("gpt-4o")
            .messages(List.of(new ChatMessage("user", prompt)))
            .temperature(0.7)
            .maxTokens(600)
            .build();

        String insights = openAiService
            .createChatCompletion(request)
            .getChoices().get(0)
            .getMessage()
            .getContent();

        // Cache insights
        redisTemplate.opsForValue().set(cacheKey, insights, Duration.ofHours(cacheTtlHours));
        return insights;
    }

    private String buildSummary(List<Expense> expenses) {
        // Total per category
        Map<Category, DoubleSummaryStatistics> byCategory = expenses.stream()
            .collect(Collectors.groupingBy(
                Expense::getCategory,
                Collectors.summarizingDouble(e -> e.getAmount().doubleValue())
            ));

        StringBuilder sb = new StringBuilder();
        sb.append("Total transactions: ").append(expenses.size()).append("\n\n");
        sb.append("By category:\n");

        byCategory.forEach((cat, stats) ->
            sb.append("  ").append(cat)
              .append(": ₹").append(String.format("%.0f", stats.getSum()))
              .append(" across ").append(stats.getCount()).append(" transactions\n")
        );

        // Append top 5 largest expenses for context
        sb.append("\nLargest individual expenses:\n");
        expenses.stream()
            .sorted(Comparator.comparing(Expense::getAmount).reversed())
            .limit(5)
            .forEach(e -> sb.append("  ")
                .append(e.getDescription())
                .append(" — ₹").append(e.getAmount())
                .append(" (").append(e.getCategory()).append(")\n")
            );

        return sb.toString();
    }
}

ExpenseController.java
@RestController
@RequestMapping("/api/expenses")
@RequiredArgsConstructor
public class ExpenseController {

    private final ExpenseService expenseService;
    private final InsightsService insightsService;

    /**
     * Main NL input endpoint.
     * Body: { "text": "i spent 300 bucks on amazon today" }
     */
    @PostMapping("/natural-language")
    public ResponseEntity<Expense> addFromText(
            @RequestBody Map<String, String> body,
            @AuthenticationPrincipal UserDetails user) {

        String rawText = body.get("text");
        if (rawText == null || rawText.isBlank()) {
            return ResponseEntity.badRequest().build();
        }
        Expense saved = expenseService.saveFromNaturalLanguage(rawText, user.getUsername());
        return ResponseEntity.ok(saved);
    }

    @GetMapping
    public ResponseEntity<List<Expense>> getAll(
            @AuthenticationPrincipal UserDetails user) {
        return ResponseEntity.ok(expenseService.getAllByUser(user.getUsername()));
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> delete(
            @PathVariable String id,
            @AuthenticationPrincipal UserDetails user) {
        expenseService.delete(id, user.getUsername());
        return ResponseEntity.noContent().build();
    }

    @GetMapping("/insights")
    public ResponseEntity<String> getInsights(
            @AuthenticationPrincipal UserDetails user,
            @RequestParam(defaultValue = "30") int days) {
        return ResponseEntity.ok(
            insightsService.generateInsights(user.getUsername(), days)
        );
    }
}

End-to-End Request Flow

How it all connects

When a user sends "i spent 300 bucks on amazon today":

1
POST /api/expenses/natural-language JWT is validated by Spring Security. Request body { "text": "..." } reaches the controller.
2
NLPParsingService.parse() Sends the text to GPT-4o with a strict JSON-only system prompt and today's date injected. Temperature is 0.0.
3
GPT returns structured JSON {"amount":300,"currency":"INR","category":"SHOPPING","vendor":"Amazon","expenseDate":"..."}
4
ExpenseService.saveFromNaturalLanguage() Maps the parsed DTO to the Expense entity. Saves raw input alongside structured fields to PostgreSQL.
5
GET /api/expenses/insights?days=30 InsightsService checks Redis cache first (TTL 1h). If miss, aggregates all expenses by category, sends summary to GPT at temperature 0.7, caches the result.
6
GPT returns personalized advice Top spending categories, unusual expenses, one saving tip, and a health score out of 10.
13

Key Design Decisions

  • Temperature 0.0 for parsing, 0.7 for insights — deterministic JSON extraction vs. natural conversational advice.
  • Always store rawInput — lets you re-parse all historical entries if your prompt improves, without data loss.
  • Redis cache on insights — AI API calls are expensive. Insights cached for 1 hour per user per time window.
  • Per-user scoping at the DB level — every query filters by userId, never only by expense ID, preventing data leakage between users.
  • Inject today's date into the prompt — the LLM has no knowledge of the current date; you must supply it for relative expressions to resolve correctly.
  • GPT-4o for both services — accurate at structured extraction and nuanced at financial advice. Swap to a smaller model for cost savings on parsing if needed.
